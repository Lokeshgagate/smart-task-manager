# Smart Task Manager - Full Stack Application

A full-stack task management web application built with Next.js (App Router), Node.js, Express, and Tailwind CSS.

---

## 🚀 Features
- **User Authentication:** Mock login supporting multiple Indian user personas.
- **Task Management:** Create, update, delete, assign, and view tasks.
- **Task Dependencies:** Set task dependencies (blocked tasks cannot be completed until dependent tasks are marked as done).
- **Filtering & Views:** Priority-based filtering (Low, Medium, High) and "My Tasks" user view.
- **Responsive UI:** Clean and modern interface built using Tailwind CSS.
